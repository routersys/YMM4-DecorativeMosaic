# 装飾モザイク for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-DecorativeMosaic.svg)](https://github.com/routersys/YMM4-DecorativeMosaic/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、素材のエッジに沿う方向場を求め、Hausnerの装飾モザイク手法で四角タイルを敷き詰めてローマ風モザイクとして描画する映像エフェクトプラグインです。
履歴フレーム、参照画像、学習済みモデルを使わず、入力された一枚の映像だけを処理します。
タイルの配置はシードから決定論的に決まり、同じ設定では常に同じ配置になります。
強さ、敷設、大きさ、目地幅、細長さ、乱れ、細部、整列、エッジ検出、立体感、色むら、目地濃度の12項目はアニメーションに対応しています。

## 概要

本プラグインはYMM4の映像エフェクトとして動作し、エフェクトの種類一覧では「装飾モザイク」として表示されます。カテゴリは装飾とアニメーションです。

入力された現在のフレームのアルファ値から素材の輪郭を、輝度の勾配から素材の内部のエッジを求めます。配置の計算はHausnerの論文「Simulating Decorative Mosaics」（SIGGRAPH 2001）に基づきます。エッジからのユークリッド距離場の勾配に直交する接線方向を方向場とし、主軸を方向場へ局所回転させたマンハッタン計量の重心ボロノイ図をLloyd反復で解きます。各反復では、ボロノイ図をジャンプフラッドで求め、各タイルを自身の領域の重心へ移動します。反復の大部分ではエッジ近傍のセルを重心計算から除外してタイルをエッジから遠ざけ、最後の数反復で除外を解いて隙間を詰めます。配置は決定論的で、同じシードと同じパラメータでは常に同じ配置になります。

敷設のパラメータは、タイルをどこまで敷き終えたかを決めます。各タイルには敷設の順位が記録されるため、敷設を時間で変えると、タイルが順に敷かれていく遷移になります。収束した位置には方向場へ揃えた四角タイルを描画し、各タイルの色はタイル中心の位置の画素から取得します。タイルの間には目地が見え、タイル表面には立体感の陰影と色むらが付きます。モザイクは素材の不透明な範囲の内側だけに描画し、元映像の上へ合成します。

計算はComputeSharpの計算シェーダーがDirect3D 12で実行します。YMM4のDirect3D 11側とComputeSharpのDirect3D 12側は、共有テクスチャと共有フェンスで接続します。通常のフレーム処理では、CPUへの画素の読み戻しを行わず、タイル位置と敷設順位の記録だけを構造の変化時に読み戻します。タイルが存在する矩形の範囲だけを描画し、素材の形状とパラメータが変わらないフレームでは配置の計算を再利用します。

このエフェクトはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-DecorativeMosaic/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として「装飾モザイク」を選択してください。

## 主な機能

### 1. 方向場に沿うタイルの敷き詰め

素材の輪郭と内部のエッジからの距離場を求め、その勾配に直交する方向へタイルの主軸を揃えます。タイルはエッジに沿って曲がる格子状に並び、手作業のローマ風モザイクのような流れになります。

エッジをまたぐタイルはLloyd反復の中でエッジから押し出されるため、輪郭の縁が明瞭に残ります。外部マスクや手動の位置指定は必要としません。

### 2. 敷設による出現の遷移

敷設は、タイルをどこまで敷き終えたかを決めます。0%では何も描画せず、値を上げるとタイルが1枚ずつ増えていきます。各タイルには決定論的な敷設の順位が割り当てられるため、表示は常に同じ順序で進みます。

敷設を時間で変えると、テキストや立ち絵がタイルで敷き詰められていく演出になります。まだ敷かれていない場所には何も描画されず、元映像がそのまま見えます。

### 3. 大きさ・目地幅・細長さ

大きさは、タイルの間隔をピクセルで決めます。小さいほどタイルの数が増え、細かい表現になります。

目地幅は、タイルの間に見える目地の割合を決めます。細長さは、方向場に沿ってタイルを細長くする度合いを決めます。細長さはボロノイの計量にも反映されるため、細長いタイルも重ならずに敷き詰められます。

### 4. 整列とエッジ検出

整列は、方向場へタイルを揃える度合いを決めます。0%では全タイルが水平に揃った格子になり、100%ではエッジに沿って流れます。

エッジ検出は、輝度の勾配から内部の輪郭を検出する感度を決めます。0%では素材の外周だけを方向場の源にします。

### 5. 乱れ・細部・立体感・色むら

乱れは、タイルごとの大きさと回転の個体差を決めます。手切りのタイルの不揃いを再現します。

細部は、エッジの近くでタイルを縮小する度合いを決めます。高いほど輪郭の表現が細かくなります。立体感はタイル表面の陰影の強さ、色むらはタイルごとの明るさの揺らぎです。目地の色と濃度も変更できます。

### 6. 品質の選択

品質は、計算格子の解像度とLloyd反復の回数をまとめて切り替えます。

| 品質 | 1タイルあたりのセル数 | Lloyd反復 | 格子解像度の上限 |
|---|---:|---:|---:|
| 標準 | 5 | 10回 | 512 |
| 高品質 | 6 | 18回 | 768 |
| 最高品質 | 8 | 26回 | 1024 |

格子解像度の上限は計算領域の長辺のセル数です。セルの大きさはタイルの間隔と上限の両方から決まり、短辺のセル数は計算領域の縦横比に合わせて決めます。

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- Direct3D 12デバイスを取得できない場合や、YMM4が使うDirect3D 11デバイスとの共有テクスチャおよび共有フェンスを作成できない場合は、エフェクトを適用せず入力映像を表示します。
- タイルの敷き詰めには現在のフレームのアルファ値と輝度だけを使用します。履歴フレーム、外部画像、学習済みモデルは使用しません。
- 計算領域は素材の範囲そのままで、長辺は8192画素が上限です。上限を超える素材には、エフェクトを適用せず入力映像を表示します。
- 方向場の変化がタイルの間隔より細かい場合、その変化は配置に反映されません。
- 処理量とGPUメモリ使用量は、計算領域の大きさと品質に応じて増えます。

## 注意事項

- 処理負荷: 最高品質は格子解像度とLloyd反復の回数が最も多いため、高品質と標準より処理負荷が高くなります。タイルの間隔を小さくするほど格子が細かくなります。描画はタイルが存在する矩形の範囲だけを計算します。
- キャッシュ: 素材の形状と輝度、タイル配置を決めるパラメータが変わらないフレームでは、配置の計算を再利用します。敷設、目地幅、乱れ、立体感、色むら、目地色、目地濃度だけを変えたフレームでは、配置を再計算しません。
- 色の参照: 各タイルの色は、タイル中心の位置の1画素から取得します。素材の形状と輝度の量子化値が変わらないフレームでは描画も再利用するため、量子化に満たない微小な色の変化は表示へ反映されないことがあります。
- 敷設0%と強さ0%: 敷設が0%のときは何も描画しません。強さが0%のときは入力を変更しません。
- シードと再現性: タイルの配置は、シードとセル位置から決定論的に算出します。時間値は配置の生成に使用しません。
- 透明部分: モザイクは素材の不透明な範囲の内側だけに描画されるため、出力範囲は素材より広がりません。タイルと目地は元映像の上へアルファ合成します。
- 更新通知: エフェクトを最初に生成したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。
